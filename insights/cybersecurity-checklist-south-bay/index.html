South Bay // Security baseline

Cybersecurity checklist for South Bay businesses.

Start with the controls that reduce the most common paths to account compromise, ransomware, and avoidable downtime.

The baseline: protect identity, keep devices current, maintain recoverable backups, train people for real scenarios, and rehearse what happens when something goes wrong.

Five checks to run this month

  1. Identity: require MFA, remove stale accounts, and review admin access.
  2. Endpoints: centrally manage laptops, patch them, and confirm protection is reporting.
  3. Backups: verify coverage, isolation, retention, and a recent restore test.
  4. People: make phishing reporting easy and practice the escalation path.
  5. Response: write down who is called, what gets isolated, and how leadership communicates.

What “done” looks like

Evidence beats assumption. You should be able to show the last backup test, current admin list, device coverage, and the owner for each response step.

If any answer is “we think so,” that is a useful priority—not a reason to panic.
