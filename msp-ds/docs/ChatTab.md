ChatTab — Source-selector chip inside the chat panel — small mono chip that turns cyan when active.

## Usage

```tsx
<div className="chatbot-source-tabs">
  <ChatTab active>Knowledge base</ChatTab>
  <ChatTab>Your tickets</ChatTab>
  <ChatTab>Contracts</ChatTab>
</div>
```

## Notes

Wrap a set in a `.chatbot-source-tabs` div for the wrapping row layout.
